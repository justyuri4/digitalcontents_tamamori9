# デジタルコンテンツ　玉森班1_9_井手和海_小坂勇輝
x24006:井手和海

アイデア
1.chatGPT作曲(自然言語toMIDI)
2.マウス操作でインタラクティブに音を出す
3.声の大きさでインタラクティブ
!4.会議の声を入力するだけで議事録作る

決定 --会議の声を入力するだけで議事録作る--
仕様(予定)
・Webアプリ
・マイク入力、音声ファイルの入力で整形、重要部だけ会話をまとめる
・話者分離(話している人の区別)
・話の内容でパートを分けて整形
・会話の中の疑問、結論が出なかった話題に解決策を自動で提案
・Webアプリ内でログ、話題や話した時間などで検索できるようにする
・話の声色などでスコアづけ(盛り上がった->はなまる,盛り上がらなかった->三角)

依存ライブラリは `requirements.txt` で管理します。仮想環境の準備後、必要に応じて `python -m pip install -r requirements.txt` を実行してください。

## 起動方法（macOS）

プロジェクトのルートで仮想環境を有効にしてから、`backend` フォルダーでサーバーを起動します。

```bash
source .venv/bin/activate
cd backend
python main.py
```

ブラウザーで <http://127.0.0.1:8080> を開きます。音声APIも同じサーバーを使います。`index/getvoice.py` を直接起動する必要はありません。

マイク録音中はWhisperXで10秒ごとに文字起こしし、SQLiteへ仮保存します。録音を停止すると、Sherpa-ONNXが録音全体を一度に話者分離し、既存の文字起こし行に話者ラベルを付けて更新します。音声ファイル入力も、WhisperXで文字起こしした後にSherpa-ONNXで話者分離して保存します。SQLiteのテーブル構成は変わらず、`processed`も`0`のままです。初回起動時はWhisperXとSherpa-ONNXのモデルを取得するため、インターネット接続が必要です。Hugging Faceのトークン設定は不要です。モデル取得後の音声処理はMac上で行い、音声を外部へ送信しません。

サーバーを終了するときは、起動したターミナルで `Ctrl+C` を押します。
