# デジタルコンテンツ　玉森班1_9_井手和海_小坂勇輝
x24006:井手和海
x250032:小坂勇輝

アイデア
1.chatGPT作曲(自然言語toMIDI)
2.マウス操作でインタラクティブに音を出す
3.声の大きさでインタラクティブ
!4.会議の声を入力するだけで議事録作る

決定 --会議の声を入力するだけで議事録作る--
仕様(予定)
・Webアプリ
・マイク入力、音声ファイルの入力で整形、重要部だけ会話をまとめる
・話者分離(話している人の区別)
・話の内容でパートを分けて整形
・会話の中の疑問、結論が出なかった話題に解決策を自動で提案
・Webアプリ内でログ、話題や話した時間などで検索できるようにする
・話の声色などでスコアづけ(盛り上がった->はなまる,盛り上がらなかった->三角)

仮想環境が変わる際pip freeze > を使ってください
pip install requests
pip freeze > requirements.txt
